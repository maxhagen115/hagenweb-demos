Goed om te weten

Staat je vraag er niet bij? Stuur gerust een appje, dan help ik je persoonlijk verder.

Hoe lang gaat een set wimperextensions mee?
Je eigen wimpers vernieuwen zich continu, dus extensions groeien mee. Gemiddeld blijft een set twee tot vier weken mooi. Daarna vullen we bij.
Brow Lamination of Henna Brows?
Lamination stylet de haartjes, zodat je wenkbrauw voller oogt. Henna geeft kleur aan haartjes én huid, waardoor lege plekjes opgevuld lijken. De twee zijn ook te combineren.
Hoe lang moet mijn haar zijn voor waxen?
Ongeveer twee millimeter, dat is zo'n twee weken laten staan. Korter pakt de hars niet goed en blijft er meer staan dan je zou willen.
